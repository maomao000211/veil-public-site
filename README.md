# Veil - Public Website and Download

Public repository for Veil product introduction and macOS installer distribution.

## What Veil does

Veil is a macOS menu bar app for focus and screen-share privacy:

- Automatically keeps the active window clear
- Dims or softens inactive windows to reduce distraction
- Helps avoid accidental exposure during meetings and recordings
- Supports quick toggle, Peek Mode, and settings from the menu bar
